# تطبيق تثبيت التعريب — 1.0.0

تطبيق Electron عربي يعمل دون إنترنت على Windows x64 وLinux x86_64. يأتي مع ملفات التعريب الثلاثة (`exelight7_P.pak` و`.utoc` و`.ucas`) ويتحقق من SHA-256 قبل نسخها. نسخة Linux تعمل على ملفات لعبة Windows المستخدمة عبر Proton، ولا تتضمن اللعبة.

## الاستخدام

1. أغلق اللعبة وافتح التطبيق.
2. اضغط «البحث في Steam» أو «اختيار المجلد» وحدد مجلد اللعبة الذي يحتوي ProjectPBZ.
3. اضغط «تثبيت التعريب» ووافق على المسار المعروض.
4. من شاشة بداية اللعبة اختر Settings → Text Language → Français.

للإزالة، افتح التطبيق واختر المجلد نفسه ثم «إزالة واستعادة». يُعيد التطبيق الملفات التي كانت موجودة قبل التثبيت، ويترك المودات الأخرى كما هي. إذا عدّلت ملفات التعريب لاحقًا، تتوقف الإزالة لحماية تعديلاتك. التثبيت اليدوي غير المسجّل بالتطبيق لا يُحذف تلقائيًا. إن وُجدت ملفات الإصدار السابق (`3BADIOH_P.*` و`ZZZ_3BADIOH_Fix_P.pak`) نُقلت عند التثبيت إلى النسخة الاحتياطية، وتُعاد عند «إزالة واستعادة»؛ لأن تعريبين معًا يتعارضان.

Linux: امنح AppImage صلاحية التنفيذ. إذا لم تتوفر FUSE، استخدم `--appimage-extract-and-run`. لا تُشغّل التطبيق بصلاحية root. نسخة Windows غير موقعة بشهادة تجارية.

## النسخ الاحتياطية واستعادة عملية انقطعت

يحفظ التطبيق النسخ السابقة داخل `ProjectPBZ/Content/Paks/~mods/.exelight7-backups/`، مع `recovery.json` يبيّن تجزئات الملفات السابقة. لا تحذف هذا المجلد قبل استعادة ملفاتك.

عند انقطاع الكهرباء أو إغلاق العملية قسرًا، أغلق كل نسخ التطبيق واللعبة أولًا. إذا بقي ملف `.exelight7.lock`، استعد الملفات السابقة من أحدث سجل `recovery.json`: انسخ الملفات ذات `previous` غير الفارغ من النسخة الاحتياطية إلى `~mods`، واحذف من ملفات التعريب الثلاثة فقط ما كان `previous` له `null`. وأعد أيضًا الملفات المدرجة في `retired` إلى `~mods`. احتفظ بالنسخة الاحتياطية، ثم أزل ملف القفل بعد التأكد من الاستعادة. لا تحذف ملفات مودات أخرى. إذا تعذّر تحديد السجل الصحيح، احتفظ بالملفات واطلب المساعدة قبل إعادة التثبيت.

## التطوير والبناء

المتطلبات: Node.js 24 وPython 3.10+. من جذر المستودع:

```bash
python3 tools/prepare_release.py
cd installer
npm ci
npm test
npm start
npm run build
```

ينتج البناء EXE محمولًا وAppImage في `dist/`. تُبنى الحزمة اليدوية بواسطة سكربت Python. بعد اكتمال التطبيقات، شغّل من جذر المستودع:

```bash
python3 tools/prepare_release.py --checksums
```

اختبار واجهة Linux على بيئة دون شاشة:

```bash
cd installer
npx electron --ozone-platform=headless --disable-gpu scripts/smoke.cjs
```

يختبر التثبيت والإزالة على مجلد مؤقت بملفات التعريب الحقيقية. خيار `--no-sandbox` استُخدم في اختبار الحاوية فقط؛ ليس جزءًا من التطبيق المنشور. الاختبارات المحلية: 16 حالة لمحرك التثبيت، و9 حالات لحزمة التعريب، واختبار واجهة Linux. تشغيل EXE على Windows وتجربة التعريب داخل اللعبة لم يتمّا محليًا.
