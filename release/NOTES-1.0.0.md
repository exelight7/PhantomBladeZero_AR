# Phantom Blade Zero بالعربية — 1.0.0

إصدار exelight7: التعريب الأساسي كاملًا مع 30 تحسينًا نصيًا جديدًا، بإجمالي 95 تعديلًا على النص الأصلي. يظهر «تعريب exelight7» بجانب زر الإعدادات عند اختيار الفرنسية.

## اختر طريقة التثبيت

| الملف | الاستخدام |
| --- | --- |
| `PhantomBladeZero-AR-1.0.0-win-x64.exe` | تطبيق محمول لـ Windows 64-bit؛ افتحه واختر مجلد اللعبة ثم «تثبيت التعريب». |
| `PhantomBladeZero-AR-1.0.0-linux-x86_64.AppImage` | تطبيق Linux / Steam Deck؛ امنحه صلاحية التشغيل ثم اختر مجلد اللعبة. |
| `PhantomBladeZero-AR-1.0.0-manual.zip` | تثبيت يدوي كامل: فك الضغط وانسخ مجلد ProjectPBZ إلى مجلد اللعبة. |
| `SHA256SUMS.txt` | تجزئات SHA-256 للتحقق من التنزيلات. |

أغلق اللعبة قبل التثبيت. في Steam: إدارة ← تصفّح الملفات المحلية. بعد التثبيت، من شاشة بداية اللعبة اختر **Settings → Text Language → Français**؛ الفرنسية هي خانة التعريب العربي.

التطبيق يعمل دون إنترنت ويحفظ نسخًا احتياطية من الملفات المستبدلة. زر «إزالة واستعادة» يعيد الملفات السابقة ويحافظ على ملفات المودات الأخرى. الحزمة اليدوية تشمل جميع الملفات اللازمة؛ لا تحتاج تنزيل المود الأساسي منفصلًا.

على Linux دون FUSE يمكن تشغيل AppImage باستخدام `--appimage-extract-and-run`. التطبيق لنسخة اللعبة المستخدمة عبر Proton. ملف EXE غير موقّع بشهادة تجارية.

## التحقق وحدود التجربة

نجحت 12 حالة لاختبار محرك التثبيت و7 اختبارات لحزمة التعريب، وفحص ZIP وتجزئات الملفات. جُرّبت واجهة التطبيق على Linux بتثبيت الملفات الحقيقية وإزالتها في مجلد تجريبي. لم تُختبر اللعبة نفسها أو تشغيل EXE على Windows محليًا.

التعريب الأساسي: 3BADIOH. التحسينات والتطبيق: exelight7. هذا إصدار مجتمعي غير رسمي ولا يحتوي اللعبة.
